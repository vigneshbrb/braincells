## ADDED Requirements

### Requirement: Responsive
Rows, hero and modal SHALL adapt at 360, 768 and 1280 pixel widths without horizontal page scroll.

#### Scenario: Responsive case 1
- **WHEN** viewport is 360 px
- **THEN** cards show 2.3 per row and the page does not scroll sideways

### Requirement: Keyboard
All interactive elements SHALL be reachable by keyboard with a visible focus ring.

#### Scenario: Keyboard case 1
- **WHEN** Tab is pressed through the home page
- **THEN** focus moves in visual order with a visible ring
